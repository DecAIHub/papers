Project card coding: passport fields and evidence checks

Instructions and FAQ — Task 1

For each project you see the card description (field values and curator scores have been removed from it) and links to sources. Note: the card description is in Russian (unpublished project content); everything else is in English. Read the description; if it is not enough — open the links (website, documentation, whitepaper, explorer). Then, for each of the four fields, pick a value from the closed list. Next to every value there is a ? icon — click it to see a short explanation of the term (definitions come from the project glossary). Progress is saved automatically in this browser — you can close the tab and come back later.

Service answers (present in every list)

  • "Cannot be determined" — sources are unavailable or contain no information. This is an honest answer; do not hesitate to use it.
  • "No suitable value in the list" — you understood what it is, but no label in the list fits. Type your own value into the field that appears.

Conservative rule: pick a value only if it follows from the description/sources. When torn between a value and "cannot be determined" — choose "cannot be determined". The per-field comment is optional (fill it in only if you had doubts or want to explain).

FAQ

Links do not open. Try the card's other links; if there is still no information — "cannot be determined".

Source in an unfamiliar language. Use a translator; if still unclear — note it in the comment.

The project looks dead/abandoned. Code what is claimed in the surviving sources; note it in the comment.

Torn between two values. Pick the more specific one and name the second candidate in the comment.

Do not discuss ambiguous cases with anyone until the work is finished — they are the subject of the study. Technical questions (a file/button does not work) are fine.

Instructions and FAQ — Task 2

Each evidence entry is a link (artifact) plus the curator's claim about what this link proves. Progress is saved automatically. For each entry:

  1. Open the link. If it does not open — tick "URL unreachable"; the second question will be skipped.
  2. Does the artifact support the curator's claim? "Fully" / "Partially" / "Does not support". Partially = the page covers the claim's topic, but not everything stated is visible.

The "Mapped to field" badge shows which card field the claim belongs to — it is context only, you do not evaluate it.

FAQ

Source in an unfamiliar language. Use a translator; if still unclear — note it in the comment.

Do not discuss ambiguous cases with anyone until the work is finished — they are the subject of the study. Technical questions (a file/button does not work) are fine.
